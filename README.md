# Healthcare Claims Analytics Dashboard

## Project Overview
End-to-end healthcare analytics project analyzing 100,000 Medicare claims
across 20 CPT procedures, 12 specialties, and 20 US states (2020–2023).

## Tools Used
- Python (Pandas, DuckDB, Matplotlib)
- SQL (DuckDB — window functions, aggregations, CTEs)
- Power BI (4-page interactive dashboard)
- Jupyter Notebook

## Key Findings
- Total knee replacement is the #1 Medicare spend procedure at ~$19B total
- Medicare pays ~40 cents per $1 billed across all specialties
- NJ pays $6 more than MA for the same office visit (CPT 99213)
- 1,251 claims flagged as payment ratio anomalies via z-score detection
- Average 3.5 services per beneficiary indicating repeat procedure utilization

## Dashboard Pages
1. Executive Summary — KPIs, top procedures, specialty breakdown
2. Procedure Deep Dive — charge vs allowed vs paid analysis
3. Geographic Analysis — state-level payment variation map
4. Utilization & Trends — year-over-year trends, overutilization outliers
